# MyReactApp 🚀

A full-stack web application built with React, TypeScript, and .NET.

## 📖 About The Project

MyReactApp is a modern full-stack application developed using React with TypeScript for the frontend and .NET for the backend.

The project follows a clean and scalable structure, focusing on reusable components, type-safe development, and communication between the frontend application and backend API.

The goal of this project is to build a maintainable application using modern web development technologies.

## ✨ Features

- ⚛️ React frontend
- 🔷 TypeScript for type safety
- 🖥️ .NET backend API
- 🔄 Frontend and backend communication
- 🧩 Reusable components
- 📱 Responsive user interface
- 🛠️ Clean project structure
- 🚀 Scalable architecture

## 🚀 Installation & Setup

### Clone the repository

```bash
git clone https://github.com/irhadTTT/MyReactApp.git
```

## Frontend Setup

Navigate to the frontend folder:

```bash
cd Client
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Frontend will run on:

```
http://localhost:5173
```

## Backend Setup

Navigate to the backend folder:

```bash
cd Server
```

Restore .NET dependencies:

```bash
dotnet restore
```

Run the backend:

```bash
dotnet run
```

## 📦 Available Commands

### Frontend
